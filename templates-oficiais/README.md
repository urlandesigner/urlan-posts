# Templates oficiais

Decisão de 27/11/2026. Regras completas em `REGRAS.md`, seção "Templates oficiais".

| Template | Quando usar | Exemplo |
|---|---|---|
| Texto escuro | Explicativo, pesquisa, novidade, opinião, história | `texto-escuro.png` (Claude Meetings) |
| Ilustrado | Explicativo que precisa mostrar uma interface | `ilustrado.png` (Black Friday) |
| Editorial | Lista de repositórios, ferramentas ou sites | `editorial.png` (Repos parte 2) |
| Combos | Paleta de cores | `combos.png` (Color combos roxo) |

- Capa: sempre a capa série (`capa-serie.png` é a mais recente). Os exemplos antigos ainda têm textos nos cantos da capa; capas novas não têm.
- Fechamento: o mesmo nos quatro, o último quadro de cada exemplo.
